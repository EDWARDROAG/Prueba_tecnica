# Landing Elevate — Parte 1

Maquetación HTML/CSS/JS de la landing de captación (Elevate / BodyBrite Academy).

## Cómo verla

Abre `index.html` en el navegador (doble clic o Live Server). No requiere build ni dependencias.

## Estructura

```
parte-1-maquetacion/
├── index.html
├── css/styles.css
├── js/main.js
└── assets/
```

## Notas

- Layout con CSS Grid (secciones) y Flexbox (barra, formulario, footer).
- Responsive: 960px y 640px.
- El formulario valida en el cliente (nombre, email, teléfono de 10 dígitos, selects). No hay backend.
